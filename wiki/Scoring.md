# AI 评分标准

## 评分维度

每张照片获得两个独立评分（0-100）：

### memory_score — 回忆价值

评估这张照片的不可替代性和情感价值。

| 分数区间 | 描述 | 举例 |
|---------|------|------|
| 0-39 | 低价值 | 截图、文档、收据、测试图片、模糊废片 |
| 40-69 | 普通记录 | 日常随手拍，有一定记录价值但不特别 |
| 70-79 | 有情感价值 | 值得留念的照片 |
| 80-89 | 重要事件 | 生日、聚会、旅行中的精彩瞬间 |
| 90-100 | 珍贵记忆 | 毕业典礼、婚礼、孩子成长、不可再现的场景 |

**加分因素：**
- 有清晰人脸/亲密关系 → +10~20
- 重要场合（婚礼/毕业/生日）→ +5~15
- 不可替代性（再也拍不到的场景）→ +10~20
- 情感强度（喜悦/感动）→ +5~10
- 风景美感 → +5~10
- 旅行场景 → +5

**特殊基准分规则：**
- 孩子/婴儿照片：基准分 75
- 宠物（猫/狗等）：基准分 70
- 家庭合照：基准分 72

### beauty_score — 美观度

评估照片的构图、光线、色彩等视觉美感。

| 分数区间 | 描述 |
|---------|------|
| 0-30 | 技术问题明显（模糊、过曝、欠曝）|
| 30-60 | 普通水平 |
| 60-80 | 好看的照片 |
| 80-100 | 摄影级作品 |

## 照片分类

分析时自动将照片归入以下分类：

| 分类 | 说明 |
|------|------|
| `人物/孩子` | 儿童/婴儿照片 |
| `人物/毕业` | 毕业相关 |
| `人物/家庭` | 家庭合照 |
| `人物/情侣` | 情侣合影 |
| `人物/自拍` | 自拍 |
| `人物` | 其他人像 |
| `猫咪` | 猫 |
| `狗狗` | 狗 |
| `宠物` | 其他宠物 |
| `旅行` | 旅行/出游 |
| `风景` | 自然风景 |
| `美食` | 食物照片 |
| `日常` | 日常生活记录 |
| `夜景` | 夜景/弱光 |
| `城市` | 城市/建筑 |
| `植物` | 花/植物 |
| `物体` | 物品特写 |
| `文档` | 文档/截图 |
| `其他` | 其他 |

## 旁白生成

每日精选页面会为每张入选照片生成两条文案：

1. **旁白 (side_caption)**: 8-20 字，像随口说的一句话（如"想去西湖边走走"）
2. **描述 (daily_caption)**: 30-60 字，像老朋友翻相册时的感想

每日使用的提示词会注入不同的随机种子，保证每次生成的文案风格不同。
