# AI 评分标准

## 评分维度

每张照片获得两个独立评分（0-100）：

### memory_score — 回忆价值

评估这张照片的不可替代性和情感价值。

| 分数区间 | 描述 | 举例 |
|---------|------|------|
| 0-39 | 低价值 | 截图、文档、收据、测试图片、模糊废片 |
| 40-69 | 普通记录 | 日常随手拍，有一定记录价值但不特别 |
| 70-79 | 有情感价值 | 值得留念的照片 |
| 80-89 | 重要事件 | 生日、聚会、旅行中的精彩瞬间 |
| 90-100 | 珍贵记忆 | 毕业典礼、婚礼、孩子成长、不可再现的场景 |

**加分因素：**
- 有清晰人脸/亲密关系 → +10~20
- 重要场合（婚礼/毕业/生日）→ +5~15
- 不可替代性（再也拍不到的场景）→ +10~20
- 情感强度（喜悦/感动）→ +5~10
- 风景美感 → +5~10
- 旅行场景 → +5

**特殊基准分规则：**
- 孩子/婴儿照片：基准分 75
- 宠物（猫/狗等）：基准分 70
- 家庭合照：基准分 72

### beauty_score — 美观度

评估照片的构图、光线、色彩等视觉美感。

| 分数区间 | 描述 |
|---------|------|
| 0-30 | 技术问题明显（模糊、过曝、欠曝）|
| 30-60 | 普通水平 |
| 60-80 | 好看的照片 |
| 80-100 | 摄影级作品 |

## 旁白生成

每日精选页面会为每张入选照片生成两条文案：

1. **旁白 (side_caption)**: 8-20 字，像随口说的一句话（如"想去西湖边走走"）
2. **描述 (daily_caption)**: 30-60 字，像老朋友翻相册时的感想

每日使用的提示词会注入不同的随机种子，保证每次生成的文案风格不同。

## 相似照片去重

基于**平均感知哈希**（aHash）的自动去重策略。

### 哈希计算

```python
img = Image.open(path)
img = ImageOps.exif_transpose(img)  # 校正旋转方向
img = img.convert("L")              # 灰度
img = img.resize((8, 8))            # 8×8 像素
pixels = list(img.getdata())
avg = sum(pixels) / len(pixels)
hash = "".join("1" if p >= avg else "0" for p in pixels)
# → 64 位二进制字符串
```

### 相似判定

使用**海明距离**比较两张照片的哈希值：

```python
def hamming_distance(h1, h2):
    return sum(c1 != c2 for c1, c2 in zip(h1, h2))
```

距离 ≤ `SIMILARITY_THRESHOLD`（默认 5/64）视为相似。

### 降分策略

```
一组相似照片 [A, B, C, D]
  评分: A=90, B=85, C=80, D=72

保留最高分: A (90)
其余降至:  B→10, C→10, D→10
```

**规则：**
- 一组中只保留回忆分最高的那张
- 其余全部降至 `SIMILARITY_PENALTY_SCORE`（默认 10 分）
- 新照片可能成为最高分保留，也可能被已有高分照片降分
- **不删除数据**，只降分处理
